# Designing Functional Tests Plugin

Designs risk-based functional test plans, manual test cases, regression slices, and automation handoff packs from requirements, URLs, or exploratory notes. Use when preparing manual QA coverage before automation, turning feature descriptions into scenario catalogs, or converting exploratory findings into structured test assets.

## What's inside

- `skills/designing-functional-tests/` — the agent skill, generated from the repository's `skills/designing-functional-tests/` directory, which is the source of truth

## Installation

Install from this repository's plugin marketplace (defined in `.github/plugin/marketplace.json`):

```
copilot plugin marketplace add jaktestowac/awesome-copilot-for-testers
copilot plugin install designing-functional-tests
```

## Note on source of truth

The skill content is a copy of `skills/designing-functional-tests/` at the repository root. Do not edit the plugin copy
directly — update the root skill and run `npm run plugin:materialize`.
